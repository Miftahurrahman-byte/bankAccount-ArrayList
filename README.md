# bankAccount-ArrayList
Program Java sederhana untuk latihan *Array dan ArrayList*. Program ini menggambarkan sistem bank: sebuah Bank menyimpan banyak Nasabah, dan setiap Nasabah menyimpan banyak Akun. Penyimpanan data menggunakan ArrayList.

## Struktur Program
- Bank.java : menyimpan daftar nasabah (ArrayList)
- Nasabah.java : menyimpan data nasabah dan daftar akunnya (ArrayList)
- Akun.java : menyimpan nomor akun dan saldo, dengan metode setor dan tarik
- MainBankAkun.java : main method untuk membuat objek dan memanggil metodenya

## Cara Menjalankan
Compile dan jalankan dengan dua perintah ini di terminal (di dalam folder program):

    javac *.java
    java MainBankAkun

## Library Tambahan
Tidak ada library tambahan. Hanya memakai java.util.ArrayList bawaan Java.
